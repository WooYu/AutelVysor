# v0.10.5：文字输入与画面放大

## 电脑上打好的中文

1. 先在手机画面中点击目标输入框，确认有光标。
2. 在工具栏文本框输入中文、数字或混合文本，点击 **Paste text**。
3. 检查手机里的实际结果；状态“Paste requested”只代表已向 scrcpy 发出粘贴快捷键，不代表 Android 应用已经接收。未确认前不要连续重发，以免重复插入。

这条现代通道用于 Android 7+，会更新电脑剪贴板并执行 scrcpy 默认的左 Alt+V 显式粘贴，不依赖 ADBKeyBoard。主窗口必须在前台，投屏必须可见，操作时释放 Ctrl/Alt/Shift/Win。它不会向后台窗口发送按键。应用的密码框、定制控件或设备策略可能拒绝粘贴。

可选的 ADB IME 流程移到 **Input options**，保留原输入法恢复与回读校验。截图中 `ADBKeyBoard command failed` 对应的是旧按钮的 IME 路径，不能据此判断所有键盘通道都不可用。

## 直接键盘打字

- **Keyboard: Auto**：Android 9+ 使用 UHID 硬件键盘；更旧系统使用 SDK 兼容通道。
- **Hardware**：直接使用手机当前输入法和物理键盘布局。可通过 **Input options → Phone hardware keyboard settings** 配置。电脑输入法已经组合好的中文，请使用上面的 Paste text。
- **Compatible**：保留 SDK raw-key-events，供硬件模式不支持或被设备拒绝时切换。切换模式会重启当前投屏，选择仅对本次会话有效。
- **Focus keyboard**：在点过手机输入框后，将 Windows 键盘焦点移回投屏。

## 看清画面

- 在 **Fit** 旁选择 **125% / 150% / 200% / 300%**。这些比例相对于适应窗口的画面大小。
- 放大后，用画面**右侧和底部滚动条**平移到上下或左右边缘；**Fit** 恢复完整画面并重置平移。
- **1:1** 仍可使用；现代投屏也可用滚动条查看被裁切的部分。
- 如果放大后文字像素模糊，在主窗口选择 **Mirror quality → High** 后重启投屏，以增加源画面清晰度。单纯放大不会增加源图像的信息。
- 竖屏保留宽高比时，在宽窗口中仍会有两侧空白。缩放、画质和 Android 字体大小是不同设置，本次不改变手机字体或显示密度。

状态栏现在最多一行高度，鼠标悬停可查看完整错误。另修复了已在 Windows 用例中复现的原生窗口尺寸滞后：WPF 区域高度改变后，投屏重新按最终客户区适配，避免底部停留在旧窗口尺寸而被截掉。

## 验证边界

未修复版本的 Windows 回归已复现现代文字按钮不进入原生粘贴、无缩放平移、多行错误挤占画面、以及 WPF 高度改变后的裁切。直接数字按键也通过真实 SendInput 和独立原生进程检查；旧测试只确认焦点，不足以证明字符到达。

原生助手接收到电脑剪贴板中的中文，只证明 Windows 到 scrcpy 风格窗口这一边界，不代替真实 Android 应用的插入验证。本环境未连接截图中的设备；请用新版在同一页面检查 `67`、中文和中英混合文本，以及放大/平移/恢复 Fit 的实际结果。代码和构建以 [PR #8](https://github.com/WooYu/AutelVysor/pull/8) 的最新检查为准。
